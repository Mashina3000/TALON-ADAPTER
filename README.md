# Электронная регистратура

Веб-приложение с React/Vite-клиентом и Express-прокси для legacy-сайта 4D.
Бэкенд использует cookiejar для сохранения сессии, axios с таймаутом 10 секунд
и cheerio для разбора HTML. Мок-сценарии позволяют проверить успех, таймаут,
HTTP 500, пустой ответ и изменённую HTML-структуру без запросов к сайту.

## Запуск

Требуется Node.js 18 или новее.

1. В `backend` скопируйте `.env.example` в `.env` и проверьте `REGISTRY_BASE_URL`.
2. Установите зависимости и запустите backend:

   ```powershell
   cd backend
   npm install
   npm start
   ```

3. В другом терминале установите зависимости и запустите frontend:

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

4. Откройте адрес Vite, обычно `http://localhost:5173`.

Для тестов выберите сценарий в списке «Режим данных». «Реальный сайт» вызывает
адрес, настроенный через `REGISTRY_BASE_URL`; остальные пункты используют локальные
HTML-заглушки.

## API

- `GET /api/districts`
- `GET /api/specialties`
- `GET /api/csrf` — выдаёт CSRF-токен для последующих POST-запросов
- `POST /api/talons` с JSON `districtId`, `specialtyId`, при необходимости `date` и `time`
- `POST /api/book` с JSON `talonId`

Для прямого вызова моков добавьте к запросу `?mock=success`, `?mock=timeout`,
`?mock=500`, `?mock=empty` или `?mock=malformed`.

## Важно

Пути 4D и названия полей формы заданы по предоставленному описанию. Реальный сайт
может требовать иные значения формы, отдельную сессию или авторизацию. Адаптер не
обходит CAPTCHA/авторизацию и не сохраняет персональные данные пациентов. Перед
публикацией проверьте разрешение на интеграцию и настройте HTTPS.
